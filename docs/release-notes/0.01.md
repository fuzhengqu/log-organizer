# 日志归档助手 0.01

常驻 Windows 托盘的归档工具：把下载、截图、日志放进中转目录（或拖进窗口），输入**纯数字问题单号**并明确确认后，才移动到目标目录下的单号文件夹。

## 下载

| 你的机器 | 下载 | 说明 |
| --- | --- | --- |
| 常见 Intel / AMD 电脑 | `LogOrganizer-0.01-win-x64.zip` | 已在 x64 机器上实机验证 |
| Windows on ARM（骁龙等） | `LogOrganizer-0.01-win-arm64.zip` | 由 CI 交叉编译，**尚未在 ARM 设备上实机启动** |

也可以直接下载裸 `LogOrganizer-0.01-win-x64.exe` / `-win-arm64.exe`。压缩包里还有微软官方 VC++ 运行库安装包与 `使用说明.txt`。

## 安装与使用

1. 解压到普通可写目录，例如 `D:\Apps\LogOrganizer`，双击 `LogOrganizer.exe`。
2. 首次启动会创建中转目录 `D:\Downloads\_收件`，可在设置里改。
3. 在设置里选**目标目录**（单号文件夹会创建在它下面）。
4. 文件进入中转目录、停止变化 10 秒后，窗口提示待归档项目；输入单号点“归档”才会移动。

不需要安装 .NET 或 Windows App Runtime（已打包成单文件）；需要 **Microsoft Visual C++ 2015-2022 运行库**，缺了会提示，运行包内 `VC_redist.*.exe` 即可离线安装。程序未签名，SmartScreen 首次运行会提示“Windows 已保护你的电脑”，选“更多信息 → 仍要运行”。

## 0.01 包含

**归档行为**
- 中转目录监控与静默期提示；未完成的下载后缀（`.crdownload`、`.part`、`.tmp` 等）自动忽略。
- 手动添加、拖放、逐项移出列表都只改列表，不动磁盘上的源项目。
- 单号只接受非空纯数字；目标单号文件夹已存在时合并；同名冲突逐项选择覆盖 / 重命名 / 跳过，默认“跳过”，绝不静默覆盖。
- 跨卷移动先复制到目标卷的临时名字，校验文件数量与大小一致后才提交并删除源项目；任何失败都保留源文件并给出原因。
- 合并或跨卷复制文件夹时不跟随其中的联接点 / 符号链接。
- 置顶模式让窗口常驻最前（透明度 40%–100% 可调），新项目直接进列表；置顶不等于自动归档。

**界面**
- 归档窗口与设置窗口共用扩展标题栏、卡片与页脚；两个窗口都能最大化、自由缩放，最小尺寸 380×460 / 460×560，位置与尺寸会被记住。
- 托盘右键菜单六项全部可用：显示 / 隐藏窗口、设置、打开中转目录、打开目标目录（未设置时置灰）、暂停 / 继续监控、退出。
- 全局快捷键唤醒：默认 `Ctrl+Shift+L`、默认关闭，设置页可捕获改键；按下后把窗口提到最前并聚焦单号框，组合被占用时提示。不再使用键盘钩子，因此不会抢走其它程序的空格 / 回车。
- 程序图标由代码逐档绘制（16–256 px），exe、窗口、任务栏、托盘与标题栏徽标一致。

**系统**
- 支持 Windows 10 1809（17763）及以上与 Windows 11；Windows 10 上自动退回纯色背景。
- 开机自启（默认关闭，只写 `HKCU`）；单实例；崩溃日志只写本机 `%LOCALAPPDATA%\LogOrganizer\crash.log`。
- 完全离线：不联网、不收集数据、无遥测、无自动更新。

## 已知限制

- **ARM64 包未实机验证**：CI 能编译并产出，但 runner 无法启动 ARM 二进制。ARM 设备上如遇问题，可改装 x64 包（Windows on ARM 支持 x64 模拟）。
- 跨卷移动只比对文件数量与大小，不做逐字节哈希。
- 批次逐项执行，不承诺文件系统事务原子性；中途失败时已完成项保留在目标，其余源项目保留并逐项说明。
- 个别受企业策略管控的目录不允许写 `%APPDATA%`，此时配置保存会失败；把 exe 放到普通目录即可，无需管理员权限。
