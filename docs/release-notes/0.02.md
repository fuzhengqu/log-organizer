# 日志归档助手 0.02

常驻 Windows 托盘的归档工具：把下载、截图、日志等文件放进**中转目录**，或直接拖入归档窗口；文件稳定后提示待归档项目。输入**纯 ASCII 数字问题单号**并明确点击“归档”后，才会移动到目标目录下的单号文件夹。

本次是界面修复版，归档行为与配置文件格式不变，可直接覆盖 0.01。

## 下载

| 屏幕架构 | 文件 | 说明 |
| --- | --- | --- |
| 主流 Intel / AMD 电脑 | `LogOrganizer-0.02-win-x64.zip` | x64 包已实机验证 |
| Windows on ARM（如骁龙本） | `LogOrganizer-0.02-win-arm64.zip` | 由 CI 交叉编译，**尚未在 ARM 设备上实机启动** |

也可以直接下载裸 exe：`LogOrganizer-0.02-win-x64.exe` / `-win-arm64.exe`；压缩包里还有微软官方 VC++ 运行库安装包与 `使用说明.txt`。

## 0.02 修复

- **置顶按钮状态**：未置顶时图钉保持倾斜，置顶后转为垂直并换成强调色；置顶底色单独占一层，鼠标仍停在按钮上时也能看出已置顶。
- **最小尺寸标题**：归档窗口最小宽度 380 → 420 DIP，“日志归档助手”不再被裁掉；两个窗口标题都加了省略号兜底。
- **设置窗口最大化**：内容随窗口拉伸到 860 DIP（与归档窗口一致）并居中，不再缩成中间一小块。

## 安装与使用

1. 解压压缩包到普通可写目录（例如 `D:\Apps\LogOrganizer`），双击 `LogOrganizer.exe`。
2. 首次启动会创建中转目录 `D:\Downloads\_收件`（可在设置中修改）。
3. 在设置里选择**目标目录**——归档文件夹会创建在它下面。
4. 文件进入中转目录并停止变化 10 秒后，会提示待归档项目；输入单号后点击“归档”才会移动。

不需要安装 .NET 或 Windows App Runtime；已打包的版本需要 **Microsoft Visual C++ 2015-2022 运行库**，缺失会提示，压缩包内附带安装包。程序未签名，SmartScreen 首次运行可能提示“Windows 已保护你的电脑”，选择“更多信息 → 仍要运行”即可。

## 已知限制

- **ARM64 包未实机验证**：CI 能编译并产出，但 runner 无法启动 ARM 二进制。ARM 设备上如遇问题，可改装 x64 包（Windows on ARM 支持 x64 模拟）。
- 跨卷移动只比对文件数量与大小，不做逐字节哈希。
- 批次逐项执行，不承诺文件系统事务原子性；中途失败时已完成项保留在目标，其余源项目保留并逐项说明。
- 个别受企业策略管控的目录不允许写 `%APPDATA%`，此时配置保存会失败；把 exe 放到普通目录即可，无需管理员权限。
