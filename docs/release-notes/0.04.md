# 日志归档助手 0.04

常驻 Windows 托盘的归档工具：下载、截图、日志等文件放进**中转目录**，或直接拖入归档窗口；输入**纯 ASCII 数字问题单号**并点击“归档”后，才会移动到目标目录下的单号文件夹中。

本次只修行为细节，归档流程与目录结构不变。

## 下载

| 屏幕架构 | 文件 | 说明 |
| --- | --- | --- |
| 桌面 Intel / AMD 机器 | `LogOrganizer-0.04-win-x64.zip` | x64 已实机验证 |
| Windows on ARM（少数场景） | `LogOrganizer-0.04-win-arm64.zip` | 由 CI 交叉编译，**尚未在 ARM 设备上实机验证** |

也可以直接下载裸 exe：`LogOrganizer-0.04-win-x64.exe` / `-win-arm64.exe`。压缩包里还有微软官方 VC++ 运行库安装包与 `使用说明.txt`。

## 0.04 变更

- **修好图钉取消不了**：置顶按钮在扩展标题栏的非客户区里，之前依赖 WinUI 自动声明的点击穿透区域。这个区域在窗口移动、缩放、切换主题后会丢失，此时点图钉不会切换状态，而是被当成拖动标题栏（实测窗口会跟着移走 280 px）。现在每次布局变化后都自己重新声明按钮矩形，连续点击也稳定；按钮也改成只从一个入口写状态，不会再出现图标与真实置顶状态不一致。
- **新文件只闪任务栏**：文件一进中转目录就出现在待归档列表，任务栏图标闪一下提醒你；不再弹“项目已准备归档”对话框、不抢前台、窗口不会自己升起来。2 秒内的连续变化只闪一次；最小化时不会自动还原。
- **删除静默检测**：不再有“文件停止变化后等待 N 秒”，设置页里对应的“静默等待秒数”一并移除；归档始终只由你点击“归档”触发。
- **删除暂停监控**：托盘菜单只剩显示 / 隐藏、设置、打开中转目录、打开目标目录、退出。置顶与监控彻底分开，置顶只负责吸顶和 92% 透明度。
- **更准确的失败提示**：文件还在被复制占用时点归档，提示“文件仍在使用中，请等复制完成后再点击归档。”

## 安装与使用

1. 解压压缩包到普通可写目录，例如 `D:\Apps\LogOrganizer`，双击 `LogOrganizer.exe`。
2. 首次启动会创建中转目录 `D:\Downloads\_收件`（可在设置里修改）。
3. 在设置里选择**目标目录**——归档文件夹会创建在它下面。
4. 文件进入中转目录后会立刻出现在列表里，任务栏图标闪一下；输入单号，点击“归档”才移动文件。

不需要安装 .NET 或 Windows App Runtime。已打包的版本需要 **Microsoft Visual C++ 2015-2022 运行库**，缺失时会提示；压缩包内附有官方安装包。程序未签名，SmartScreen 首次运行可能提示“Windows 已保护你的电脑”，选择“更多信息 → 仍要运行”即可。

## 已知限制

- **ARM64 尚未实机验证**：CI 能编译并产出，但 runner 无法启动 ARM 二进制。ARM 设备上如遇问题，可改装 x64 包（Windows on ARM 支持 x64 模拟）。
- 跨卷移动只校验文件数量与大小，不做逐字节哈希。
- 批次逐项执行，不承诺文件系统事务原子性；中途失败时已完成项目留在目标，其余源项目保留并逐项说明。
- 运行企业策略管控目录时可能写不进 `%APPDATA%`，此时配置保存会失败；把 exe 放到普通目录即可，不需要管理员权限。

## 校验

`SHA256SUMS.txt` 与附件一一对应：

```
certutil -hashfile LogOrganizer-0.04-win-x64.zip SHA256
```
